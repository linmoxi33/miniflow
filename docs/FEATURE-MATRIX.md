## 部署成本

| 指标 | Airflow 3.3.2 | miniflow 0.1.0 |
|---|---|---|
| 第三方依赖 | 130 个（完整解析） | 0 |
| 常驻进程 | 5 | 1（或 0） |
| 元数据库 | 必需（Postgres/MySQL/SQLite） | 内置 SQLite |
| Windows 原生 | ❌ 需 WSL2 | ✅ |
| 首次跑通 | 分钟级 | 秒级 |
| 单机内存占用 | 数百 MB 起 | 数十 MB |

> Airflow 侧数字抓取于 2026-10-20，复现方法见 `DEPLOY.md` 第 8 节。

## 一句话选择建议

- 需要**图形界面 / 多人协作 / 跨机器分发** → Airflow
- 需要**单机、按时间、可靠地跑完几个脚本** → miniflow
- 两者都要 → 核心链路留 Airflow，边角脚本挪 miniflow
